# Make scanned PDFs searchable

**Task:** Turn local scanned pages into a PDF with searchable text using [NAPS2](https://www.naps2.com/). **Platforms:** Windows, macOS and Linux. **Preparation:** Install NAPS2 and download the OCR languages before going offline.

## Before disconnecting

Open the OCR setup and download the languages used in your document. For mixed-language pages, prepare each language you need. If scanning from a physical device, install its driver and confirm that it is available. You can instead start with existing local image files or a scanned PDF.

## Workflow

1. Work from a copy of the original scan and import its pages into NAPS2, or scan locally.
2. Check orientation, page order and readability before OCR.
3. Enable **Make PDFs searchable using OCR** and select the prepared language or languages.
4. Save to a new PDF file. An existing text layer is normally preserved rather than OCRed again.
5. Open the new file in a PDF viewer. Search for several known words and try selecting and copying text.
6. Compare names, numbers and a passage near the end with the scan. A successful export alone does not show that recognition is accurate.

The output is a searchable PDF, not a re-created editable Word document. NAPS2 does not directly export OCR results as a plain text file; copy recognized text from a PDF viewer if needed.

## Source and verification

Based on the official [NAPS2 OCR documentation](https://www.naps2.com/doc/ocr), reviewed on 25 October 2026. This walkthrough was not executed during this session.

## 中文任务概述

先联网下载所需 OCR 语言包，再导入本地扫描件，开启可搜索 PDF 选项并另存。最后用搜索和复制文字检查结果，重点核对数字、人名和混合语言。输出为带文字层的 PDF，不等同于可编辑 Word。
